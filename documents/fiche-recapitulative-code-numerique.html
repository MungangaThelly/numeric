Code du numérique de la RDC — Fiche récapitulative

Outil pédagogique Mboka · Campagne nationale de vulgarisation · Usage libre pour les volontaires et enseignants

À retenir en une phrase : Le Code du numérique (Ordonnance-loi n° 23/010 du 13 mars 2023) organise l’espace numérique congolais, protège les personnes et fixe des responsabilités.

1. Les 6 thèmes essentiels

  • Comprendre le Code — cadre général (art. 1)
  • Données personnelles — protection et droits (art. 183–270)
  • Cybersécurité & fraude — protéger systèmes et comptes
  • Documents électroniques — écrits et signatures
  • Services & commerce numériques — plateformes et transactions
  • Responsabilité en ligne — contenus, haine, désinformation

2. Bons réflexes (à pratiquer)

  • Avant de partager une information : vérifier la source.
  • Face à un discours de haine ou une injure : ne pas relayer, signaler.
  • Données personnelles : ne donner que ce qui est nécessaire.
  • Code secret / mot de passe : ne jamais le communiquer par message.
  • Accusation sans preuve : refuser de publier.

3. Messages pour la discussion de groupe

  • Pourquoi la désinformation est dangereuse pour la cohésion nationale ?
  • Que faire si un ami partage une fausse information ?
  • Quels droits ai-je sur mes données personnelles ?

4. Rappel important

Mboka est un outil pédagogique. En cas de divergence, le texte officiel de l’Ordonnance-loi n° 23/010 fait foi. Les contenus Mboka ne constituent pas un avis juridique.
