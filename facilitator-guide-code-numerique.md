# Guide facilitateur — Code du numérique (Mboka)

**Public :** Volontaires UNV / animateurs communautaires de la campagne nationale de vulgarisation du Code du numérique  
**Durée conseillée d’une séance :** 30 à 45 minutes  
**Outil :** Mboka (module « Mboka Numérique ») — https://mboka.nuhar.se ou version installée  

---

## 1. Objectif de la séance

À la fin de la séance, les participants doivent pouvoir :
- Expliquer simplement ce qu’est le Code du numérique
- Citer au moins 3 droits ou devoirs concrets (données personnelles, responsabilité en ligne, cybersécurité)
- Savoir quoi faire face à la désinformation ou aux discours de haine

---

## 2. Déroulement recommandé (45 min)

| Temps | Activité | Support Mboka |
|-------|----------|---------------|
| 0–5 min | Accueil + pourquoi le Code est important | Introduction orale |
| 5–15 min | Parcours des 6 thèmes (aperçu rapide) | Module Mboka Numérique → cartes de thèmes |
| 15–30 min | Quiz citoyen (6 à 10 situations) | Quiz du module |
| 30–40 min | Discussion : désinformation, haine, responsabilité | Cas pratiques + échanges |
| 40–45 min | Synthèse + engagement personnel | Fiche récapitulative imprimable |

---

## 3. Messages clés à retenir (à dire clairement)

1. **Le Code protège** les personnes et organise l’espace numérique congolais.
2. **Données personnelles** : on ne donne que ce qui est nécessaire.
3. **Désinformation** : vérifier avant de partager.
4. **Discours de haine / injures** : ne pas relayer, signaler.
5. **En cas de doute** : consulter le texte officiel ou une personne de confiance.

---

## 4. Conseils pratiques pour les volontaires

- Utilisez le mode hors-ligne si la connexion est faible (progression locale).
- Imprimez la fiche récapitulative d’une page avant la séance.
- Laissez les participants répondre au quiz ; corrigez ensemble.
- Notez les questions difficiles pour un retour ultérieur.
- Rappelez toujours : Mboka est un **outil pédagogique**, pas un avis juridique.

---

## 6. Questions fréquentes des participants

| Question | Réponse simple |
|----------|----------------|
| Le Code s’applique-t-il aux réseaux sociaux ? | Oui, plusieurs dispositions concernent les contenus et la responsabilité en ligne. |
| Puis-je être sanctionné pour un partage ? | Cela dépend du contenu et de l’intention. Mieux vaut vérifier avant de partager. |
| Où trouver le texte officiel ? | Liens indiqués dans Mboka (sources officielles). |
| Mboka remplace-t-il la loi ? | Non. C’est une adaptation pédagogique. Le texte officiel fait foi. |
